### Current project

🃏 **[blackjack-engine](https://github.com/lysapala93/blackjack-engine)** — a Python Blackjack simulation engine built as an explicit phase state machine. No blocking `input()`, no hidden game loop: just a small synchronous API, so the same engine can be driven by a human in the terminal or by a scripted / reinforcement-learning agent. Fully covered by pytest — and my playground for connecting Python, clean design and machine learning.
